# Dream IT Company – EPAM Systems

**Team:** Lili Bús, Larina Haluska

## Project Goal

This presentation explores our “dream IT company” through the example of **EPAM Systems**. It highlights the professional environment, growth opportunities, and skills needed to start a career as a junior software engineer.

## Presentation Overview

### EPAM Systems

EPAM is a global digital engineering and consulting company. Its motto, *“Engineering the Future,”* reflects its focus on building digital products, platforms, and experiences.

### About EPAM

- Founded in **1993**
- Headquartered in **Newtown, Pennsylvania, USA**
- Provides digital engineering, cloud, AI-enabled transformation, and consulting services
- Has offices in **Budapest, Szeged, and Debrecen**
- Works on international projects with thousands of engineers in Hungary

### Why EPAM?

EPAM can be an attractive workplace for people who want to grow in IT:

- **EPAM University:** internal training, courses, and mentoring
- **International projects:** work with Fortune 500 companies
- **Engineering culture:** strong focus on technology and professional excellence
- **Flexibility:** hybrid work and modern offices

### Technologies

EPAM works with a wide range of technologies:

- **Backend:** Java, Spring, .NET, C#, Python, Go, Rust
- **Web and mobile:** React, Angular, Node.js, TypeScript, Swift, Kotlin
- **Cloud and data:** AWS, Azure, Google Cloud, Big Data, AI, DevOps, CI/CD, Kubernetes

### Projects

EPAM develops business-critical systems for large international companies, including:

- **Fintech:** secure trading platforms processing millions of transactions
- **E-commerce:** global online stores for major fashion brands
- **Media:** high-traffic streaming platforms for international media companies

### Junior Engineer Roadmap

To start as a junior developer, useful skills include:

- Programming basics in Java, C#, JavaScript, or Python
- Git and version control
- Algorithms and problem-solving
- Basic knowledge of Agile methods
- English at B2 level or higher
- Teamwork, curiosity, and independent learning

### Junior Software Engineer Role

A junior software engineer may:

- Write and debug application code
- Take part in code reviews and technical discussions
- Create technical documentation
- Learn and apply new technologies

Typical expectations include an IT-related degree, personal projects or a GitHub portfolio, motivation to learn, and good English skills.

### Culture and Growth

EPAM emphasizes collaboration, continuous learning, and professional development. Its global community includes more than 50,000 professionals, with events, tech talks, and hackathons supporting learning and networking.
